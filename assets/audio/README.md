# Audio assets

## Home ambience

- `home-fireplace.ogg` — “Fireplace” by inchadney, CC0.
- `home-wind.ogg` — “Wind” by felix.blume, CC0.

The seamless OGG loops are distributed by the
[Muges/ambientsounds](https://github.com/Muges/ambientsounds) project, whose
README links the original recordings and confirms their CC0 licenses.
