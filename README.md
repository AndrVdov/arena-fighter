# Arena Fighter

Arena Fighter — однопользовательская браузерная RPG об автоматических боях на арене, развитии героя, экипировке и управлении потребностями.

Текущая версия: **1.0.0**.

## Возможности

- создание героя и распределение характеристик;
- уровни, опыт, золото и развитие персонажа;
- тренировочные и смертельные автоматические бои с критическими ударами и уклонением;
- противники разных рас, уровней и рангов;
- инвентарь, экипировка, сундук, магазин и расходники;
- голод, жажда и сон, влияющие на характеристики;
- дом, арена, магазин, река, шахта и глобальная карта;
- работа в шахте с доходом от действующей Силы;
- шесть локальных слотов сохранения.

## Технологии

Проект использует Vanilla JavaScript, HTML и CSS. Сборщик, серверная часть и внешние зависимости отсутствуют. Сохранения хранятся в `localStorage` браузера.

## Запуск

Запустите любой статический HTTP-сервер из корня проекта. Например:

```powershell
python -m http.server 8000
```

После этого откройте `http://127.0.0.1:8000/`.

Открытие `index.html` напрямую может работать не во всех браузерах одинаково, поэтому локальный HTTP-сервер предпочтительнее.

## Структура

```text
assets/       изображения и фоны
css/          стили интерфейса
js/data/      контент и баланс
js/entities/  игровые сущности
js/systems/   игровые правила и сохранения
js/ui/        экраны и модальные окна
js/Game.js    жизненный цикл и координация игры
```

Подробное техническое задание находится в `arena-fighter-spec.md`, а актуальный контекст разработки — в `docs/PROJECT_CONTEXT.md`.
